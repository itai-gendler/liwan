# Send event batch — all entities unknown id

## Trigger

A valid key has all direct source scope and submits valid Pageviews for an unregistered source ID.

## Outcome

The all-direct scope admits that ID using resolved global policy, bypassing the registered-source existence check. Its stored history has no required registered-source relation.

## Edge cases

- Acknowledgement is not a persistence receipt; async append errors are separately represented by accepted-write-lost.
