# Eligible exits update only the latest matching Pageview monotonically within thirty minutes

Eligible exits select the latest matching source/group/page Pageview lacking a following Pageview within the bounded period; updates are monotonic and capped at 30 minutes; ignored exits create no counted event. Timing links Pageviews partitioned by source/group. Exit processing is delayed, then matches source/group/page against the latest eligible Pageview with no qualifying following Pageview in the bounded session. Measurements do not exceed 30 minutes and only increase. Custom events never supply Pageview timing links.
